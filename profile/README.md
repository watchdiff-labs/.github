# WatchDiff Labs

**Official libraries, SDKs, and integrations for WatchDiff.**

WatchDiff Labs provides developer tools for integrating WatchDiff across languages, frameworks, and deployment environments.

## Installation

### Python

```bash
pip install watchdiff-core
```

### JavaScript / TypeScript

```bash
npm install watchdiff-core
```

### PHP with Composer

```bash
composer require watchdiff-labs/watchdiff-core
```

## Docker

```bash
docker pull watchdifflabs/watchdiff
```
